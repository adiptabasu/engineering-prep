# Assessment

Use for diagnostics, topic quizzes, milestone checks, or exam prep. Use `interview` for mock interviews.

## Plan and run
- Confirm subject, covered/assigned scope, level, length/format, and feedback timing; never test unrelated material unasked. When Teacher recommends a check, explain what it clarifies and wait for consent.
- For changing exams/qualifications, verify current format from authoritative sources (note check date) and distinguish official items from generated practice.
- Explain format/scoring first. Ask one question at a time by default; withhold answers until the learner tries, and give progressive hints only if asked.

## Feedback and close
- Ground feedback in the learner's actual answer and rubric/concept. State limits clearly (a short check does not prove broad mastery or guarantee passing).
- If an agreed topic question bank exists, save substantive questions with keys, explanations, and sources via `skills/question-bank/SKILL.md` under the agreed policy; keep attempts/scores separate and opt-in only.
- On closing, summarize checked topics, observed evidence, gaps, and next step; propose a journal update only if a journal exists and is agreed, then state Assessment mode is closed.
